# Proposal

## Why

Личные рецепты сейчас лежат где попало, и при каждой готовке приходится пересчитывать количества под нужное число порций в уме и отдельно составлять список покупок. Нужно одно приложение на телефоне, где рецепт хранится вместе с ингредиентами, сам масштабируется по порциям и превращается в список покупок, работающий в магазине без интернета.

## What Changes

Это новый проект с нуля: в репозитории пока нет кода, только каркас OpenSpec.

- Веб-приложение, которое устанавливается на телефон как PWA и работает офлайн. Бэкенда нет, все данные хранятся на устройстве.
- Рецепты: название, свободное текстовое описание, одна необязательная картинка, базовое число порций и список ингредиентов. Количество у ингредиента необязательно («по вкусу»), единица выбирается из фиксированного списка или задаётся своя.
- Выбранное число порций сохраняется в рецепте. Количества пересчитываются от базового числа порций и округляются в зависимости от типа единицы.
- У каждого ингредиента есть галочка «куплено» и кнопка «Сбросить отметки» в рецепте. При смене порций галочки не меняются.
- Общий список покупок по выбранным рецептам. Некупленные ингредиенты попадают в него автоматически, одинаковые продукты с совместимыми единицами складываются. Можно дописывать свои пункты, купленное уходит вниз зачёркнутым, а «Очистить купленное» удаляет купленные ручные пункты.
- Коллекции работают как метки: рецепт может состоять в нескольких. Их можно создавать, переименовывать и удалять.
- Оценки «Отлично», «Хорошо», «Иногда можно попробовать», «Плохо» окрашивают фон рецепта в зелёный, голубой, жёлтый и светло-красный соответственно.
- В каталоге рецептов есть поиск по названию и фильтры по коллекции и по оценке.
- Данные можно экспортировать в JSON-файл (вместе с картинками) и восстановить из него. Приложение просит у браузера постоянное хранилище.

За рамками: синхронизация между устройствами и пользователями, тёмная тема, нумерация шагов, сравнение «похожих» названий продуктов (например «мука» и «мука пшеничная»).

## Capabilities

### New Capabilities

- `recipes`: создание, просмотр, редактирование и удаление рецепта: название, описание, картинка, базовое число порций, ингредиенты с количеством и единицами.
- `servings-scaling`: сохраняемое число порций рецепта, пересчёт количеств ингредиентов и правила округления и отображения по типу единицы.
- `ingredient-checklist`: отметки «куплено» у ингредиентов рецепта и их сброс.
- `shopping-list`: выбор рецептов для покупок, общий список с суммированием одинаковых продуктов, ручные пункты, купленные пункты и их очистка.
- `recipe-collections`: коллекции-метки и их управление.
- `recipe-ratings`: оценка рецепта и цветовое оформление по ней.
- `recipe-catalog`: главный экран со списком рецептов, поиском по названию и фильтрами по коллекции и оценке.
- `local-data`: офлайн-работа и установка, локальное постоянное хранение, экспорт и импорт данных.

### Modified Capabilities

Нет: в проекте ещё нет спецификаций.

## Impact

- Новое приложение в корне этого репозитория: Vue 3, Vite, TypeScript.
- Новые зависимости: `vue`, `vue-router`, `dexie`, `vite-plugin-pwa`, а для тестов `vitest`, `@vue/test-utils`, `fake-indexeddb`.
- Код публикуется в публичном репозитории https://github.com/Maeglian/dar-recipes, а приложение раздаётся через GitHub Pages по адресу `https://maeglian.github.io/dar-recipes/`. Деплой выполняет GitHub Actions.
- Данные живут только в IndexedDB браузера на устройстве пользователя. Они не защищены от удаления вместе с данными браузера, отсюда экспорт и импорт.
