# Spec Delta

## Purpose

Работа приложения без сервера и без интернета: хранение всех данных на устройстве, установка на телефон и резервная копия через экспорт и импорт файла.

## ADDED Requirements

### Requirement: Локальное хранение
Все данные (рецепты, картинки, коллекции, отметки, выбранные порции, выбор рецептов и пункты, добавленные вручную) SHALL храниться только на устройстве и сохраняться между запусками приложения. Приложение MUST NOT отправлять данные на какой-либо сервер.

#### Scenario: Перезапуск
- **WHEN** пользователь создаёт рецепт, закрывает приложение и открывает его снова
- **THEN** рецепт со всеми данными на месте

### Requirement: Работа офлайн
После первой загрузки приложение SHALL полностью работать без подключения к сети, включая просмотр, создание и редактирование рецептов и работу со списком покупок.

#### Scenario: Без интернета
- **WHEN** устройство без сети, и пользователь открывает приложение
- **THEN** приложение загружается, а все функции работают

### Requirement: Установка на устройство
Приложение SHALL поддерживать установку на главный экран телефона и запуск в отдельном окне без интерфейса браузера.

#### Scenario: Установка
- **WHEN** пользователь добавляет приложение на главный экран и запускает его с иконки
- **THEN** приложение открывается в отдельном окне с собственным названием и иконкой

### Requirement: Постоянное хранилище
При запуске приложение SHALL запрашивать у браузера постоянное хранилище. Если браузер отказал или не поддерживает его, экран «Данные» MUST показывать предупреждение, что данные могут быть удалены браузером, и рекомендацию установить приложение и регулярно делать экспорт.

#### Scenario: Хранилище не постоянное
- **WHEN** браузер не предоставил постоянное хранилище
- **THEN** на экране «Данные» показывается предупреждение с рекомендацией сделать экспорт

### Requirement: Экспорт данных
Экран «Данные» SHALL позволять сохранить все данные приложения, включая картинки, в один JSON-файл с датой в названии.

#### Scenario: Экспорт
- **WHEN** пользователь нажимает «Экспорт»
- **THEN** скачивается файл вида `recipes-backup-2026-10-16.json`, содержащий все рецепты с картинками, коллекции и пункты, добавленные вручную

### Requirement: Импорт данных
Экран «Данные» SHALL позволять восстановить данные из файла экспорта. Импорт MUST полностью заменять текущие данные и выполняться только после подтверждения. Если файл повреждён или не является файлом экспорта этого приложения, текущие данные MUST оставаться без изменений.

#### Scenario: Восстановление
- **WHEN** пользователь выбирает файл экспорта и подтверждает замену
- **THEN** данные приложения в точности соответствуют содержимому файла, включая картинки, отметки и выбранные порции

#### Scenario: Некорректный файл
- **WHEN** пользователь выбирает файл, который не является файлом экспорта приложения
- **THEN** показывается сообщение об ошибке, а текущие данные не меняются

#### Scenario: Файл экспорта предыдущей версии
- **WHEN** пользователь импортирует файл, сохранённый до появления отметки «Приготовлено»
- **THEN** данные восстанавливаются, рецепты с оценкой считаются приготовленными, а рецепты без оценки входят в «Новое»

#### Scenario: Отмена импорта
- **WHEN** пользователь выбирает файл и отменяет подтверждение
- **THEN** текущие данные не меняются
