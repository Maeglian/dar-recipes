# Spec Delta

## Purpose

Главный экран со всеми рецептами в виде карточек, с поиском по названию и фильтрами по коллекции и оценке, чтобы быстро находить нужный рецепт.

## ADDED Requirements

### Requirement: Каталог рецептов
Главный экран SHALL показывать все рецепты карточками с названием, картинкой (если она есть), оценкой и отметкой выбора в список покупок. Рецепты MUST быть упорядочены по названию в алфавитном порядке. Нажатие на карточку открывает рецепт.

#### Scenario: Открытие рецепта
- **WHEN** пользователь нажимает на карточку «Блины»
- **THEN** открывается экран рецепта «Блины»

#### Scenario: Нет рецептов
- **WHEN** в приложении ещё нет рецептов
- **THEN** главный экран показывает подсказку и кнопку создания рецепта

### Requirement: Поиск по названию
Каталог SHALL фильтровать рецепты по вхождению строки поиска в название без учёта регистра.

#### Scenario: Поиск
- **WHEN** пользователь вводит «блин»
- **THEN** в каталоге остаются только рецепты, в названии которых есть «блин» в любом регистре

### Requirement: Фильтры по коллекции и оценке
Каталог SHALL позволять выбрать одну коллекцию, включая встроенную «Новое» первым пунктом, и одну оценку, включая вариант «без оценки». Поиск и фильтры MUST применяться одновременно. Если ни один рецепт не подходит, показывается сообщение и действие «Сбросить фильтры».

#### Scenario: Коллекция и оценка вместе
- **WHEN** выбраны коллекция «Завтраки» и оценка «Отлично»
- **THEN** в каталоге остаются только рецепты из «Завтраков» с оценкой «Отлично»

#### Scenario: Фильтр «Новое»
- **WHEN** выбрана коллекция «Новое»
- **THEN** в каталоге остаются только рецепты без отметки «Приготовлено»

#### Scenario: Ничего не найдено
- **WHEN** поиску и фильтрам не соответствует ни один рецепт
- **THEN** показывается сообщение «Ничего не найдено» и действие «Сбросить фильтры», которое очищает поиск и фильтры
